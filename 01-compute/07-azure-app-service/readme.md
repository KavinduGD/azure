# Azure App Service

- Lets you run web apps without managing infrastructure.
- Supports multiple languages and frameworks (e.g., .NET, Java, Node.js, Python).
- Provides built-in auto-scaling and load balancing.
- App service plan can be scaled up and down based on your needs.
- build and host web apps, background jobs, mobile back-ends, and RESTful APIs
- App Service supports Windows and Linux
- supports automated deployments from GitHub, Azure DevOps, or any Git repo for continuous deployment.
- more than one app can be hosted in the same App Service plan, allowing you to share resources and reduce costs.
