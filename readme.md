# Azure Cloud Learning Repository

This repository contains my comprehensive notes, diagrams, and practical examples from my journey learning Microsoft Azure Cloud services. The content is structured to cover core Azure concepts including Compute, Network, Storage, and general Azure Infrastructure.

## What I Learned

Throughout this course, I have gained in-depth knowledge and hands-on experience with the following Azure services and concepts:

*   **Introduction & Global Infrastructure**: Understood the basics of cloud computing with Azure, and explored the Azure global infrastructure including Regions, Availability Zones, and data centers.
*   **Compute Services**: Mastered the fundamentals of **Virtual Machines**, **Azure Virtual Desktop**, and containerized workloads using **Azure Container Instances (ACI)**, **Azure Container Apps**, and **Azure Kubernetes Service (AKS)**. Also explored serverless computing with **Azure Functions** and web application hosting with **Azure App Service**.
*   **Networking**: Deep dived into **Virtual Networks (VNet)** architecture, creating subnets for isolation. Implemented network security using **Network Security Groups (NSG)**, managed connectivity with **Endpoints**, and configured name resolution using **Azure DNS**.
*   **Storage Solutions**: Learned to architect durable storage solutions encompassing **Azure Storage Accounts** and its core services: **Disk Storage**, **Blob Storage**, **Azure Files**, **Azure Queue Storage**, and **Azure Table Storage**.
